# CLAUDE.md

This repository is a website built from [website-starter](https://github.com/danjamk/website-starter). The person who owns it may not be technical. The website recipe in [agentic-guides](https://github.com/danjamk/agentic-guides) sets it up and runs the interviews.

## Project state

The person's plan, profile and interview answers live in `docs/project/`. Read them at the start of every session, before doing anything else:

1. Switch to `main` and run `git pull`.
2. Read `docs/project/PLAN.md` and tell the person the "Next up" line, unless they already asked for something.
3. Read `docs/project/profile.md`.
4. If a file in `docs/project/interviews/` has `**Status:** in progress`, mention it in one line.

The format, the save rules and the resume rules are in website-state-v1.0:
https://raw.githubusercontent.com/danjamk/agentic-guides/main/website/STATE.md

Read that file before writing to anything in `docs/project/`. Changes that only touch `docs/` go straight to `main`. Every other change goes on a branch with a preview first.
