# Interviews

Each interview Claude runs with you saves its questions and your answers here, one file per interview (`discovery.md`, `brand.md`, `sitemap.md`, `page-about.md`). You can stop an interview at any point; the next session picks up at the first unanswered question.

The file format is defined in [website/STATE.md](https://github.com/danjamk/agentic-guides/blob/main/website/STATE.md) in agentic-guides.
